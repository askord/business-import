# Business Import Site

Этот проект представляет собой сайт для компании, занимающейся импортом из Китая. Включает в себя функционал поиска товаров через 1688 API (OTAPI), управление статьями через админ-панель и SEO-оптимизацию.

## Структура проекта

- `backend/`: Python Flask сервер (обработка API, поиск, база данных).
- `src/`: Frontend на Next.js (App Router).
- `database.sqlite`: База данных SQLite (в корне).

## Предварительные требования

- Node.js 18+
- Python 3.10+
- Ключ RapidAPI для 1688 OTAPI.

## Установка и запуск

### 1. Настройка окружения

Создайте файл `.env` в корневом каталоге и заполните его:

```env
RAPIDAPI_KEY=ваш_ключ_rapidapi
ADMIN_USER=admin
ADMIN_PASS=admin
JWT_SECRET=ваш_секретный_ключ
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```

### 2. Запуск Бэкенда (Python Flask)

Перейдите в папку backend, установите зависимости и запустите сервер:

```bash
cd backend
pip install -r requirements.txt
python app.py
```
Сервер запустится на `http://localhost:5000`.

### 3. Запуск Фронтенда (Next.js)

В корневом каталоге проекта установите зависимости и запустите сервер разработки:

```bash
npm install
npm run dev
```
Сайт будет доступен по адресу `http://localhost:3000`.

## Основные разделы

- **Главная страница (`/`)**: Поиск товаров, информация об услугах.
- **Статьи (`/articles/[slug]`)**: Полезные материалы об импорте.
- **Админ-панель (`/admin`)**:
  - Логин: `/admin/login` (используйте ADMIN_USER/ADMIN_PASS из .env).
  - Управление статьями: `/admin/articles` (создание, редактирование, удаление).

## SEO

- Динамический `sitemap.xml` доступен по адресу `/sitemap.xml`.
- Каждая статья имеет свои мета-теги для лучшей индексации.
